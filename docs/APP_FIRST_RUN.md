# App 首次使用指南（1.3）

面向家庭管理员与家人。产品语言使用「家庭空间 / 家庭同步」；这是你们
自己部署的服务，没有官方云。

## 管理员：创建我的家庭

1. 首次打开 App，选择「创建我的家庭」（需要家人空间管理员先在 VPS 完成
   部署，见 docs/QUICKSTART_SELFHOST.md）。
2. 填写家庭空间地址（如 `https://capsule.example.com`），App 会检测实例
   并显示其状态；地址必须以 https 开头。
3. 新实例：输入部署时的一次性初始化令牌 + 你的称呼/邮箱/密码，创建首个
   管理员并自动登录。
4. 在 App 内填写家庭名、孩子称呼与出生日期、你的称呼与关系、家庭时区
   （默认取手机时区）→ 建立家庭并开始同步。

中断（断网、退出、重启）不会丢账号：重新登录会回到同一步继续，不会要求
清空数据，也不会把新账号误判成“登录已过期”。

## 同步授权：先同意，再上传

连接成功后，如果本机有等待上传的记录，App 会明确显示目标家庭空间与
记录数量，由你选择：

- 同步全部本机记录；
- 选择要同步的记录（逐条勾选）；
- 仅保留在本机（不上传，原件不删）。

网络恢复、切前后台都不会绕过这道授权。切换账号/家庭/实例后需要重新
授权——旧队列不会被“当前凭据”发给新家庭。

## 家人：加入家庭

1. 管理员在 App「更多 → 邀请家人加入」选择身份与有效期，生成二维码或
   一次性链接（只显示一次）。
2. 家人首次打开 App 选「加入家人的家庭」，扫码或粘贴链接。
3. App 显示将要加入的家庭与身份；确认后设置自己的称呼/邮箱/密码，
   注册成功自动登录——两台设备、两个独立账号、同一个家庭。

邀请链接是高熵一次性凭据：转发给谁，谁就能用掉它。过期/撤销/已使用的
邀请会被明确拒绝；已注册过的邮箱请直接用「已有账号登录」。

## 本机记录：即存即看

拍照、录音、写文字保存后立即可以打开阅读（时间轴点本机条目进入详情），
与是否联网、是否上传、是否整理无关。详情页如实区分：

- 保存：已保存本机；
- 同步：等待上传 / 已送达收件箱 / 已入档 / 上传失败（可重试）；
- 整理：收件箱待整理 / 已入档。

上传失败不会删除原件；「保留本机」只停止等待上传；「删除」才是不可恢复
的操作且有单独确认。

## 本机救援包（设置 → 本机救援包）

导出：把尚未同步的本机记录（文字全文、原件、SHA-256 清单）打包成 ZIP，
通过系统分享保存到 App 之外。只含你自己的本机资料，不含任何登录凭据，
不是完整家庭备份。恢复：选择救援包文件，校验通过后导入为本机记录
（默认仅本机保存，不会自动上传到当前家庭）。
