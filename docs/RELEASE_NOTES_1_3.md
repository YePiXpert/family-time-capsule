从部署到全家使用 · 1.3.0-alpha.1 prerelease

本版交付一条真实使用链：VPS 一次部署 → App 内初始化管理员并建立家庭 →
本机照片即存即看 → 明确同意后向该家庭同步 → 家人扫码/受邀注册 →
两台设备、两个独立账号共享同一家庭 → 一键快照、升级、回退与诊断。

- 首次启动：App 四入口欢迎页（创建我的家庭 / 加入家人的家庭 / 仅本机记录 /
  已有账号登录）；实例识别接口让 App 能确认连接的是自家部署；未建家庭的
  账号不再被误报“登录已过期”，中断后可继续完成初始化。
- 邀请家人：管理员在 App 内生成一次性邀请（本地二维码 / 系统分享 / 复制），
  家人扫码或粘贴链接，预览确认家庭后用自己的邮箱注册并自动登录加入。
- 本机即存即看：拍照、录音、写文字保存后立即可以打开阅读，与是否联网、
  是否上传、是否整理无关；文件缺失如实报错；保存 / 同步 / 整理状态分离；
  收件箱“确认”会带上你刚编辑的标题、时间、人物与地点一次提交。
- 同步授权：首次上传必须明确同意（全部 / 部分 / 仅本机），网络恢复或切
  前后台不会绕过；切换账号或家庭后需重新授权，旧队列不会发给新家庭；
  “保留本机”永不删除原件；本机救援包可导出/恢复未同步记录。
- 自托管运维：新增 `scripts/ops/ftc` 命令套件（install / status / doctor /
  backup / restore / upgrade / rollback 等）、Caddy 自动 HTTPS 与已有反代
  两种部署模式、停写一致性快照、升级失败分级处置与回退保护。详见仓库
  docs/QUICKSTART_SELFHOST.md 与 docs/OPERATIONS.md。
- 原生展示版本 **1.3.0**，Android versionCode / iOS buildNumber 均为 **11**；
  服务器数据库新增迁移 0040（实例标识表）。

发行附件：Android APK（测试签名）、明确未签名的 iOS IPA、运维脚本包
（ops-scripts）、release-manifest.json 与 SHA256SUMS；服务器镜像发布于
ghcr.io/yepixpert/family-time-capsule（tag 与 digest 见 manifest；首次发布
后如不可公开拉取，请在 GitHub 包设置中调整可见性）。

如实声明：本版的验证来自自动化测试（单测 / 集成 / 组件 / 运维脚本套件，
CI 全绿）与 CI 中的包级检查；尚未完成真实 VPS 与真机的端到端验收，不在此
宣称。APK 为测试签名，覆盖升级需同签名；IPA 未签名，需自行签名部署。不要
卸载含唯一资料的旧包，升级前请先完成备份。
