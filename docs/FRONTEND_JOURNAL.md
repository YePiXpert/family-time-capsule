# 小美成长记 · 成长手帐与视频导入修复

2026-09-09，原生构建 17。

## 本次交付

- Web 与原生统一暖白、奶油、蜜桃色，以及字号、间距和圆角规范。
- 成长、成长册、我的三个目的地；记录是独立浮动动作，原有草稿与分享路由继续兼容。
- 成长首页使用真实孩子档案计算年龄，照片优先。无生日、不明确的孩子档案不生成假月龄。
- 导航和浮动按钮使用轻玻璃；原生 Android 12+ / iOS 模糊，旧设备、减少透明度时使用实底。
- 编辑器保持实底，原生保存操作与读者范围在滚动时可见；录音波形使用实际信号。
- 新建成长书提供照片册、图文成长记；复用原有出版器，预览、PDF、EPUB、离线阅读包共享纸张与文字色。历史来信模板继续兼容。
- 缺失或通用 MIME 的 MOV/MP4 等文件按已知格式补足声明；服务器仍检查内容和大小，HTML 伪装视频仍拒绝。
- 远端视频解码失败时尝试兼容转码；Android 阅读器使用 textureView 避免视频 Surface 与滚动容器重叠。
- 已保存的本机混合记录进入时间轴，按账户/家庭作用域隔离；成功同步后只显示服务端记录，不因旧草稿复活已删除内容。

## 精简与保留

移除独立记录页签、旧导航装饰、重复 MIME 对照表与时间轴中单独占位的批量选择卡片。
复用原件、断点上传、持久草稿、播放器、相册、导出和备份；保留现有读者权限与历史数据。
本次是前端风格和媒体可靠性更新，不将此前讨论的全部产品重构假记为已经实现。

## 验证口径

- 自动化覆盖原生持久记录重启、作用域隔离、现有录音与分享、原生减少透明度与过期偏好查询。
- 浏览器验证真正可播放的 H.264 MOV：空 MIME 导入、本机预览、原字节保存、Range 请求和服务端播放。
- 实际生成 10 位 HEVC MOV，验证兼容产物为 H.264/yuv420p 且原件字节不变。
- Web 检查 CSP 下主题色、375/768/1024/1440px 无横向溢出、大字模式、键盘与减少动态效果。
- 成长册验证预览、生产 worker 导出、离线阅读包和备份恢复。
- 原生 APK/IPA 由交付提交的 mobile-build.yml 构建。自动化和打包结果不能代替真实手机安装、相册授权及录制验收；iOS 包留给 owner 自行签名。
