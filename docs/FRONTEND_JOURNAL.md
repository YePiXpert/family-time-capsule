# 小美成长记 · 成长手帐与视频导入修复

2026-09-09，原生构建 17。

## 本次交付

- Web 与原生统一暖白、奶油、蜜桃色，以及字号、间距和圆角规范。
- 成长、成长册、我的三个目的地；记录是独立浮动动作，原有草稿与分享路由继续兼容。
- 成长首页使用真实孩子档案计算年龄，照片优先。无生日、不明确的孩子档案不生成假月龄。
- 导航和浮动按钮使用轻玻璃；原生 Android 12+ / iOS 模糊，旧设备、减少透明度时使用实底。
- 编辑器保持实底，原生保存操作与读者范围在滚动时可见；录音波形使用实际信号。

- 缺失或通用 MIME 的 MOV/MP4 等文件按已知格式补足声明；服务器仍检查内容和大小，HTML 伪装视频仍拒绝。
- 远端视频解码失败时尝试兼容转码；Android 阅读器使用 textureView 避免视频 Surface 与滚动容器重叠。
- 已保存的本机混合记录进入时间轴，按账户/家庭作用域隔离；成功同步后只显示服务端记录，不因旧草稿复活已删除内容。

## 精简与保留

移除独立记录页签、旧导航装饰、重复 MIME 对照表与时间轴中单独占位的批量选择卡片。
复用原件、断点上传、持久草稿、播放器、相册、导出和备份；保留现有读者权限与历史数据。
本次是前端风格和媒体可靠性更新，不将此前讨论的全部产品重构假记为已经实现。

## 验证口径

- 自动化覆盖原生持久记录重启、作用域隔离、现有录音与分享、原生减少透明度与过期偏好查询。
- 浏览器验证真正可播放的 H.264 MOV：空 MIME 导入、本机预览、原字节保存、Range 请求和服务端播放。
- 实际生成 10 位 HEVC MOV，验证兼容产物为 H.264/yuv420p 且原件字节不变。
- Web 检查 CSP 下主题色、375/768/1024/1440px 无横向溢出、大字模式、键盘与减少动态效果。
- 成长册验证预览、生产 worker 导出、离线阅读包和备份恢复。
- 原生 APK/IPA 由交付提交的 mobile-build.yml 构建。自动化和打包结果不能代替真实手机安装、相册授权及录制验收；iOS 包留给 owner 自行签名。

## 构建 18：记录页与导航重排

- 记录页采用独立的 CSS Module，限制书写宽度，移除桌面误显示的手机顶栏；不再让全局组件样式覆盖响应式隐藏和页面宽度。
- 素材入口以照片、视频为主，拍摄、录音、文件合并到紧凑工具行；文字采用无嵌套边框的书写区，补充信息折叠为一行。
- Web 保存条在手机、平板和桌面持续可见，原有读者选择移到保存旁；保存完成后仍显示可见范围。原生使用紧凑的固定顶部保存行，素材和文字使用相同视觉层级。
- 桌面侧栏收窄、记录动作靠近导航、账号区独立；未改变家庭权限、草稿同步、媒体存储或作品数据。
- 浏览器回归覆盖 720px 高度下手机、平板、桌面的保存与读者入口；检查 320–1440px 布局、200% 文字及原有键盘、减少动态效果和大字模式。
- 原有混合草稿恢复、无 MIME MOV 导入与播放、隐私保存、AI 故障和原生录音/相册交互继续验证。原生构建号递增为 18；实际设备验收仍需安装后完成。

## 构建 19：MPG 导入与兼容播放

- 补齐 MPG/MPEG、M1V/M2V 的文件识别、MPEG 内容头校验和服务端转码输入；MPEG program stream 与 elementary stream 分别使用对应解复用器。
- 已保存在本机但未能开始上传的 MPG 草稿可原地重试，原件不重新选取、不覆盖；原生旧待上传项发送时重新规范 MIME。
- 记录页在不支持直接播放且原件已上传时自动请求兼容 MP4，完成后切换播放器；区分等待、失败与权限错误。
- 上传启动失败明确区分格式、大小、登录和权限，不再笼统提示网络问题。
- 使用真实 MPEG-2 文件验证分片 HTTP 上传、原字节保存、H.264/yuv420p 转码；浏览器复现 415 拒绝后同一草稿重试并实际播放兼容版。另测裸 MPEG 视频序列与伪装 HTML 拒绝。

## 构建 22：手帐插画与液体玻璃

- 使用内置 imagegen 生成纪念盒与纸张成长册两张插画，接入 Web/原生成长首页和成长册入口。原始素材及完整提示词位于 `mobile/assets/illustrations/`，随原生包提供，离线可用；装饰不写入家庭记忆或出版内容。
- 修复上一版“有模糊、看不见”的原因：原生额外暖白遮罩不透明度为 82%，Web 为 88%；Web 生产 CSS 优化还丢弃了标准 `backdrop-filter`，导致 Chromium 完全没有模糊。
- iOS 26+ 在运行时 API 和编译支持检查通过后使用 `expo-glass-effect` 原生 Liquid Glass。旧 iOS/Android 12+ 保留真实背景模糊，增加透色渐变、亮边和悬浮阴影；旧 Android 使用暖白实底。
- Web 对 Safari 前缀与标准滤镜分别做能力检测，保证生产构建保留两种属性。导航与记录按钮独立采样页面；深色模式使用深色玻璃。正文、编辑器和作品纸张仍保持实底。
- 减少透明度时立即回到实底；Web 高对比度模式也关闭透明效果。减少动态效果时关闭按压缩放。玻璃只覆盖导航和浮动记录动作。
- 原生兼容性回归覆盖 iOS 原生玻璃、API 不可用、旧系统/缺少 Android 采样目标、透明度偏好即时变更及过期查询；浏览器直接检查生产构建的滤镜，并验证减少透明度。
- 本地验证：原生 331 项测试、类型检查、lint、Expo Doctor 21 项与 iOS/Android JS 导出通过。APK 与未签名设备 IPA 由交付 `main` 提交的 `mobile-build.yml` 构建；真实手机安装与光学效果仍需设备验收，浏览器截图仅证明 Web 展示。
- Web 生产构建、类型检查、lint（无错误）通过；时间轴、成长出版流程与无障碍共 12 项浏览器回归通过。另用虚构家庭实测两张插画加载、严格 CSP、320/375/768/1024/1440px 无横向溢出、200% 文字、减少透明度和导航点击。

## 构建 23：全面液态玻璃与 iOS 交互

- 玻璃从导航扩展到全界面，分 dock/card/sheet/overlay 四级，材质参数（模糊、渐变、亮边、压暗层）集中于共享令牌 `journalGlass`，Web 与原生同源。正文与成长册纸张保持实底。
- 交互对齐 iOS：大标题滚动收缩页头（Web `CollapsingPageHeader`、原生 `CollapsingHero`、push 屏原生 large title + 模糊页头）；确认与提示改用底部玻璃弹层（原生 `GlassSheet` 替代 27 处 Alert，Web 窄屏确认框下置）；时间线卡片支持滑动操作与长按快捷菜单；新增触觉反馈（可在设置关闭）。
- 原生 tab 屏重做信息层级：成长、成长册、我的均使用收缩 hero + 玻璃卡片；记录页冷蓝玻璃并入暖色体系。Web 端侧栏、页头、记忆卡、书架、表单控件同步玻璃化。
- 降级不变：减少透明度/高对比度即时实底，减少动态效果关闭位移与缩放，旧 Android 暖白实底。
- 原生 345 项测试、Web 930 项测试、两端类型检查与 lint 通过；Web 生产构建产物确认保留双引擎 `backdrop-filter`。APK 与未签名 IPA 由交付提交的 mobile-build.yml 构建，真实设备的光学效果与手势体验仍需装机验收。
