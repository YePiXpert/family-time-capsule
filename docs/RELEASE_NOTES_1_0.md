家庭记忆精简版 · v1.0.0-dev.1（构建 16）

Web、Android 与 iOS 统一为「记忆、记录、作品」三个主要入口。记录页面只需一次保存，自动保留本机草稿；标题、日期、人物和读者可按需补充。相册与家庭书先选材生成预览，再进入完整编辑，支持章节、版式、裁切焦点、版本恢复和导出。

独立故事、口述史任务、访客投递箱、定时胶囊与每周回顾流程已移除。家庭成员在记忆中的讲述、原件、权限、离线记录和作品下载仍保留。自动 AI 整理只使用已授予的自动处理权限。

升级与兼容性：

- 网页在服务端部署后刷新即可使用。
- 构建 14 及更早的原生 App 与新版首页接口不兼容，需要安装本 Release 的新版；单独升级服务器不会更新 App 界面。
- 本次任务先前提供的构建 15 已适配新版服务端，可以继续使用；构建 16 是这次带固定 Release 下载入口的发布构建。
- Android APK 已签名。覆盖安装需要与原安装包使用同一签名；不要为了更新而先卸载含有未同步内容的 App。
- iOS IPA 为 arm64 真机未签名包，需要所有者自行签名，同时处理主应用和分享扩展及其 App Group。
- 升级服务端前保留完整备份。版本 4 导出不包含已移除模块；旧备份中的核心记录仍支持恢复。若旧家庭书引用独立故事，迁移会要求先转换来源。

附件包含 APK、未签名 IPA、运维工具、SHA256SUMS.txt 和 release-manifest.json。清单记录同一 main 提交、原生构建号、服务端镜像 digest 和附件哈希。

这是 development 通道的预发布版，不是稳定版 v1.0.0。自动化验证与实际真机签名、安装验证分别记录，不用编译成功代替真机验收。
