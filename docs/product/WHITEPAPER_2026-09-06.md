# 家庭时间胶囊:产品白皮书与实现蓝图(归档基线)

**核心承诺:随手留一刻,全家能看懂;AI 帮忙整理,原件始终属于你。**

本文不保证商业爆款。竞争事实、设计建议与验证目标分别标注;目标是建立可测试的长期口碑产品。

## 执行摘要:先成为一个家庭离不开的产品

产品不是"照片库 + AI + 更多菜单",而是让真实生活低负担地留下来,被家人回应,并在多年后仍然可读、可带走。

建议定位:一款私有、可自托管的家庭记忆产品。以孩子成长为入口,以全家共同讲述为关系,以完整迁移和长期维护建立信任。它与 DadKit 独立,不延伸为喂养、尿布、任务、购物或公共社交平台。

"爆款"不能由白皮书保证。这里给出的是可验证的产品假设和执行方法:先验证一个家庭是否持续记录与回看,再验证其他家庭能否自主安装、邀请和使用。没有留存证据,不把功能数量、GitHub star、下载量或 AI 输出量当作产品成功。

| 关键决策 | 推荐答案 |
| --- | --- |
| 先赢谁 | 有新生儿/幼儿、重视隐私,且愿意自己或请亲友维护一台家庭空间的家庭。 |
| 核心体验 | 记录立即可读;家人低门槛参与;月度逐渐成册;不用时也能完整带走。 |
| AI 的位置 | 优先命名、转写、去重复整理负担;其次带来源检索和草稿,绝不充当历史事实裁判。 |
| 架构选择 | 端侧持久草稿与原件 + 自托管模块化单体 + 有界任务 worker;不从微服务开始。 |
| 商业边界 | 不卖儿童数据、不让受邀长辈逐人付费、不以收费墙阻止导出。 |
| 首发红线 | 已知丢数据/越权/无法恢复问题为零;关键原生路径有真机证据。 |

可记住的承诺:随手留一刻,全家能看懂;AI 帮忙整理,原件始终属于你;二十年后,不依赖我们也能打开。

### 与 Goal 的差异登记(执行时决策覆盖)

1. **模型路由固定**:文字/图片/标题/标签/摘要/多素材/故事草稿 → 用户自有 CPA → `gpt-5.6-luna`;录音/视频音轨转写 → MiMo API → `mimo-v2.5-asr`。白皮书第 16 章的"多供应商选型"收敛为这两条默认路由,不新增 DeepSeek/MiMo 多模态/第三个 embedding 默认服务。
2. **P0/P1/P2 是依赖顺序**:白皮书标注"后续"的 P1/P2 产品目标(自然语言辅助检索、近似分组、轻量访谈等)纳入同一正式 1.0 Goal,不自动推迟。
3. **导航**:一级入口为 今天/记忆/记录/家人/我的(五入口),收件箱下沉。

以下为白皮书正文各章要点(完整章节结构保留;与需求追踪相关的验收细节已并入 docs/release-1.0/):

## 1. 定位与市场:自托管是承诺,也是门槛

不争夺"所有人的所有照片";先解决"一个家庭怎样长期保存自己的真实故事"。

- 第一目标用户:孩子 0–3 岁、家庭成员异地、重视照片与声音保全的家庭;每家只需一位发起者能管理 VPS/NAS。
- 三种分发模式(自己部署/他人协助/官方托管):首发默认自己部署;官方托管是另一个战略决策,不能暗中把项目改为 SaaS。
- 一句话区隔:不是一个等待整理的网盘,而是一段随时能打开、能被家人补充、最终能带走的家庭生活。
- 成功不是用户每天停留一小时,而是忙碌时十几秒也能留下一刻,长辈能无障碍回应,几年后能准确找到。

## 2–3. 竞品地图(要点)

- 家庭参与类(FamilyAlbum/Tinybeans/Qeepsake/Remento/Day One/时光小屋/亲宝宝):借鉴"记录一次全家看到"、问题降低写作门槛、声音优先口述成文、共享边界;不复制无限容量承诺、邮件原图外发、每日打卡压力、排行榜。
- 照片工程类(Apple/Google Photos/Immich/Ente/PhotoPrism/Nextcloud Memories):借鉴后台处理、检索与明确平台限制;不立即复制完整底层设施、RAW 管理器、NAS 平台;相册导入/标准文件/可选适配优先。
- 未公开的内部实现(模型、数据库、留存率)一律记未知,不从界面倒推。

## 4. 真正值得借鉴的机制与差异化

低门槛私密分享/提示帮助开始写/声音变可读/自动组织/回顾成作品/隐私与保全——每项都明确"不该复制的副作用"(公开传播链、每日欠债红点、生成文冒充原话、导入时间冒充拍摄时间、只能在服务存续时打开、把私密相册宣传成 E2EE)。

四项壁垒:体验(各角色轻松完成)、数据(高质量来源/时间/独立讲述)、信任(改错可追溯、离开可带走、损坏可恢复)、执行(跨端多格式长期一致)。

## 5. 用户与十八年生命周期

六种角色(发起者/记录者/长辈观看者/偶发贡献者/儿童到青少年/成年子女);家庭变化(多孩子、双胞胎、多监护人、历史称呼、家庭分离、监护变化);记录节奏随年龄改变;年龄展示来自可核实生日与家庭时区,未知用精度字段。

## 6. 信息架构与第一次价值

五入口:今天/记忆/记录/家人/我的;收件箱为整理入口不占一级导航。首次启动四路径(创建家庭/加入家庭/已有账号/暂时本机)。首次价值验收:排除安装与传输,短流程留首条内容并立即打开,不先读说明、不先配 AI。

## 7. 原始资料与记忆:两层而不是两道门

资料库层(原件+基本字段,立即可看)与记忆层(多素材+多讲述)分离;导入 500 张不制造 500 日记或 500 审核任务。对象关系(素材/草稿/记忆/相册/作品)与重要限制(原字节不被覆盖、授权删除不受阻、移除相册项不删来源)。本机落盘成功与服务器已收到分开。

## 8. 家人共写与声音

三种贡献并存(补一句/补素材/请家人讲一段);重要原话提升为独立 Contribution;免账号贡献不免限制读取;长辈体验一屏四动作;保护真实表达(转录/整理稿/原声三层,不把"我记得可能是"改成确定年份)。

## 9. 回顾、作品与时间胶囊

回顾只提供一个有用的下一步;可跳过/静音/关闭;敏感日期与人物屏蔽;家人离世后不自动祝寿、不合成语音。作品是可继续编辑的项目(PDF/EPUB/ZIP);时间胶囊分清仪式和加密;可带走不保证在线链接永久。

## 10. 账号模型

Instance/User/AuthIdentity/FamilyMembership/Person/Guardian+Consent/GuestGrant 分离;两类管理员(家庭/实例);账号状态可继续(bootstrap/注册/家庭初始化持久幂等)。

## 11. 权限矩阵与派生内容

owner/admin/editor/contributor/viewer/guest 能力表;基础受众(仅自己/指定成员/家庭);权限检查覆盖正文/封面/缩略图/Range/搜索/计数/AI 描述/作品/下载/通知;派生内容读者不超过全部来源共同允许范围;采用 AI 建议是写操作。

## 12. 注册、登录、恢复与设备

App 内完成首用与邀请;邀请只存 hash、预览不消耗、原子 claim;成熟认证组件(密码/Passkey/管理员 TOTP+恢复码);无邮件时本机受审计恢复 CLI;PKCE 外部代理;设备会话列表与撤销;五项必测场景。

## 13. 退出、删号、成长接管与继承

退出与删除分开;App 内删号(平台要求);原件字节不变≠禁止删除;孩子逐渐成为参与者(不按照片年龄/18 岁自动解锁);传承是安排不是自动判断死亡;纸质书与已下载包无法远程删除须导出前说明。

## 14. AI 功能地图

规则层(立即做,不称 AI)/P0 整理助手/P0 口述成文/P1 辅助选材/P1 找回记忆/P1 回顾草稿/P2 对话引导;明确不做:自动确认亲属身份、育儿/疾病诊断、心理标签、成长预测、贡献排名、逝者或孩子声音合成。

## 15. AI 流水线、命名与事实边界

Job DAG(依赖/重试/检查点/租约/去重键含 promptVersion);三名称分离(originalFilename/displayTitle/event.title)与五种来源;历史 IMG 名不自动覆盖;任务运行中人工改名/删除/撤同意/改读者范围写回前再核验;三个例子界定"可给出/不应给出"。

## 16. AI 选型、评测、用量与隐私(按 Goal 收敛)

两路固定默认(见上文差异登记);文字/图片/ASR 分别配置测试;capability profile;~200 样本评测集;每能力低并发/批次/日限额;失败分类/Retry-After/取消;用量未知记未知;API 不训练≠零保留;默认不全库回填。

## 17. 安全与加密:不要承诺互相冲突的事

四种模式(自托管+TLS/端侧 ML/外部 AI/真正 E2EE)明文边界表;权限缩小≠远程抹除所有副本;处理告知"哪些资料→发给谁→为了什么→保留多久/未知→如何关闭"。

## 18. 推荐技术架构

模块化单体(SQLite WAL + 文件存储 + 持久任务)+ 有界 worker;移动 React Native/Expo + SQLite;所有客户端共享"身份、时间、权限、来源、幂等"契约;共享类型不代替运行时校验。

## 19. 数据模型与 API 契约

六领域实体表(身份/资料/记忆/整理AI/组织作品/保全)与关键约束;时间字段三分(捕获/发生/导入)与精度;API 边界(bootstrap/会话/邀请/上传/记忆/建议采用/增量/导出);幂等键+expectedRevision+稳定 cursor;哈希去重与授权分离。

## 20. 离线、同步与冲突

端侧提交顺序(暂存→校验→原子落盘→outbox);同步状态机(本机→已保存→授权→待上传→上传中→已收到→关联;暂停/仅本机/失败);目的地绑定四元组;增量与一致性(单调序列+tombstone+安全重建);冲突保留两份;本机救援。

## 21. 媒体格式、导入与外部生态

照片/视频/声音/Live Photo/文档处理表;Android Photo Picker 与 URI 授权生命周期;标准 tus 语义续传;不能承诺任意云图库一键全量同步(Google Photos API 2025 变化);与 Immich/Nextcloud 先显式导入或只读适配。

## 22. 一键部署、升级和诊断

ftc 命令表(install/adopt/status/doctor/backup/verify/upgrade/rollback/restore/rescue/ai configure+test);固定版本镜像与清单;幂等安装不换密钥不重开初始化;数据迁移是回退关键(A/B/C/D);移动发行长期经营(签名/渠道)。

## 23. 十八年保全:备份、恢复与交接

四种副本类型表;检查等级(已生成/已上传/结构已验证/原件已校验/隔离恢复演练通过);SQLite Online Backup 语义;独立故障域副本;维护者消失的离线交接说明。

## 24. 合规、滥用防护与未成年人

PIPL 儿童敏感信息与家庭事务例外;COPPA 适用性评估;风险面最低措施表(邀请滥用/文件解析/AI 注入/账号会话/外部服务/商店分发);隐私范围覆盖第三方效果图与支持日志。

## 25. 质量指标与发布门禁

指标表(首条记录/本机保存 p95/移动稳定性/授权数据零容忍/性能规模/恢复);必须测试真实边界(组件/集成/真实 Docker/设备模拟器 Release);故障注入清单;可观测但不追踪家庭生活。

## 26. 增长与可持续商业

一个家庭付费不给长辈设门票;18 年存储示例计算(仅假设);口碑增长路径;不靠焦虑文案。

## 27. 北极星指标与真实验证

每周"有新记录并发生一次主动回看或补充"的家庭数;激活/家人可用性/家庭留存(W4≥40%、W12≥25% 为待验证门槛)/AI 价值/信任/维护负担;研究设计(20 家庭定性→50–100 家庭 12 周);没有遥测也能研究。

## 28. 交付路线:按证据门槛,不按菜单数量

A 可信基础→B AI 减负→C 家庭节奏→D 长期经营;每阶段完整用户价值与停止扩张判断线;团队边界与 Agent 纵向任务方式;里程碑交付材料清单。

## 29. 复用清单、否决项与终局验收

复用矩阵(照片工程/认证上传出版/备份加密/模型数据);许可证逐仓库锁定核对;十个必须真实演示的场景;需要现在做出的五个决策(首发自托管/资料记忆双层/长辈免账号不免读取/AI 只是有来源的助手/导出与删除不付费);终局:因为好用愿意留下,因为信任敢于保存,即使离开也不会丢失自己的生活。
