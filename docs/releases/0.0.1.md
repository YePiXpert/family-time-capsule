# 小美成长记 0.0.1

用于家庭照片、视频、声音和文字的私人档案应用。本次把已有功能整理为新的 `0.0.1` 早期发行版，原生构建号为 **35**。

## 本版内容

- 成长时间轴、成长册和“我的”三入口；先保存在本机，再经授权同步到家庭服务器。
- 移动端账号、本机快照、同步、系统分享和生命周期分别管理；读取失败提供保留资料的重试页。
- 奶油纸色、陶土色主操作和内容优先的记录卡片；支持浅色、深色及大字号。
- 照片、文字、声音和视频导入，TS/MPG 等旧视频可生成兼容播放版本；AI 整理保持可选。
- 升级使用一致快照与新卷隔离验证，验证通过后切换正式服务；回滚需先准备恢复资料并完成权限、删除对账。

## 下载与安装

- `FamilyTimeCapsule-android.apk`：Android arm64 独立安装包，构建号 35。
- `FamilyTimeCapsule-ios-unsigned.ipa`：iPhoneOS arm64 设备包，主应用及分享扩展均为构建 35，需自行签名后安装。
- `family-time-capsule-ops-0.0.1.zip`：同一提交的运维工具。
- `release-manifest.json`、`SHA256SUMS.txt`：源码提交、镜像 digest、包版本与文件校验值。

服务镜像：`ghcr.io/yepixpert/family-time-capsule:0.0.1`（linux/amd64）。部署时使用 manifest 中的固定 digest，并明确传入 `--version 0.0.1`。

## 从旧版本升级

`0.0.1` 是重新编号后的版本，发布序号 **18** 高于 `1.0.0-dev.3` 的 17。
升级工具按照注册表序号判断前进，不能按 SemVer 字面大小判断降级。
已有数据继续沿当前数据库迁移链运行，本次没有新增数据库迁移。

先更新运维工具，再按仓库 `docs/UPGRADE.md` 执行升级。保留原有会话密钥、实例配置和数据；升级期间会短暂停写。
网页更新后刷新即可，App 的新界面需安装新包。构建 15 及以上沿现有协议兼容，构建 14 及更早版本需更新。

## 验证范围

发布构建执行 Web、移动端、运维、浏览器端到端和真实 Docker 的升级/快照恢复检查。
iOS Release 模拟器覆盖首次欢迎、本机空库、有记录、重启、读取失败恢复、修复后重启、深色和大字号八个场景，检查原有本机记录保留。
具体源码与构建记录以 release manifest 及同一提交的 GitHub Actions 为准。

本版属于 development 通道，GitHub 标记为 prerelease。Android 使用测试签名；iOS 包未签名。
iOS 27 beta 真机、系统分享及真实设备媒体行为仍需实际设备验收；模拟器与包校验不替代这些结果。
