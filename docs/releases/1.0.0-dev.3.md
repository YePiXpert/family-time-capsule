# 小美成长记 · 旧视频导入修复（构建 25）

TS、MTS、M2T、M2TS 视频现在可以识别、分块上传并生成兼容播放版。文件选择器允许选择被系统标为普通文件的旧视频，导入后仍按文件类型和实际内容校验。MPG 的常见 MIME 别名也统一识别。

- 补齐 MPEG-TS 同步包校验，以及 MPEG、MPEG-TS 的时长、分辨率读取与转码。
- MPEG-2 视频和 AC-3 音轨转换为 H.264/AAC MP4，原件独立保留。
- 较小视频保持原分辨率，避免无意义放大消耗转码时间和输出额度。完整约 8 分钟的 TS 样本已验证通过。
- 本机解码失败时，说明原件已保留，并指引保存、同步后生成兼容播放版；不会自动上传未经授权的本机内容。

## 升级与验证

服务器升级后刷新网页；原生端安装构建 25。营销版本为 `1.0.0`，产品与服务端版本为 `1.0.0-dev.3`。本版没有新增数据库迁移。

两个完整 MPEG-2/AC-3 视频样本已通过分块上传、完整转码、时长和音视频编码校验，保存的原件 SHA-256 与输入一致。回归覆盖 DVD program stream、TS、M2TS、错误文件头，以及网页保存重试后切换兼容播放版。

兼容播放版由服务器生成。离线保存原件不等于设备拥有 MPEG-2/AC-3 解码能力；不能直接播放时，需要保存并同步后再生成兼容版。

Android APK 使用测试密钥签名，覆盖安装需要原包签名一致；请保留未同步内容，不要先卸载旧版。iOS IPA 为 arm64 真机未签名包，需要自行签名主应用与分享扩展。尚未完成真实 Android/iOS 设备的签名安装和播放验收。本版仍为 development 通道预发布。
