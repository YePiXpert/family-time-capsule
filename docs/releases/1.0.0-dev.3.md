# 小美成长记 · 运行时与部署重构（构建 33）

这次重构围绕记录保存、启动恢复和部署数据安全展开。移动端仍先保存本机资料，经明确授权后再同步到家庭服务器。

- 将移动端状态入口拆为账号会话、本机快照、同步、系统分享和生命周期模块；完整本机快照统一更新，旧连接的异步结果失效。
- 首次读取失败时显示保留资料的重试页；页面渲染异常可以重试，运行中的同步协调器继续保留。
- 弹窗请求排队处理，退出时结束所有等待；旧动画回调不会误关下一张弹窗。完整导航树配置手势根容器。
- 升级先停写并备份，复制到新卷后隔离迁移验证；通过才成对更新镜像和卷，并强制重建正式容器。候选失败不会改变原卷。
- 快照回滚改为准备、权限对账、启用三步；准备阶段退出 28 明确表示尚未切换。启用前重新验证原件和数据库，原卷、故障卷与恢复资料保留。
- 部署命令共用实例锁，防止其他操作在备份或回滚期间重启服务。备份清理拒绝零保留数量。

营销版本为 `1.0.0`，产品版本为 `1.0.0-dev.3`。原生构建号 33，本版没有新增档案数据库迁移。原有文字、照片、声音、视频导入及 MPEG-2/AC-3 兼容播放能力继续沿现有数据模型运行。

回归包含真实 SQLite 的启动/重试、并发弹窗，以及真实 Docker 的迁移后退出、实际卷切换、回滚读取和 worker 启动失败。iOS Release 模拟器检查扩展为首次欢迎、本机空库、本机有记录、重启、坏草稿读取恢复页、修复后重启六种场景；最终检查结果以交付提交对应的 CI 产物为准。

安装包包含 Android APK 和 arm64 iOS 未签名设备 IPA。iOS 主应用和分享扩展需自行签名。此构建仍属于 development 通道；模拟器检查不替代 iOS 27 beta 真机验收。操作方式见 [升级与回滚](../UPGRADE.md) 和 [移动端运行时](../MOBILE.md)。

## 构建 34：纸上日常设计试用

参考 Claude 的 DESIGN.md，建立本项目的 [设计规范](../../DESIGN.md)，应用到原生首页与公共组件：奶油纸色、陶土主按钮、中文阅读式标题，文字记录卡片直接呈现内容，保存状态收在卡片末尾。工具行可换行，筛选触控区域增至 44；深色主题保留独立语义色。恢复页将诊断信息收进可展开的错误详情。

原生构建号增至 34。iOS Release 模拟器在原有六个启动/恢复场景之外，新增深色模式和大字号场景；结果以该交付提交的 CI 产物为准。本次变更不包含数据库迁移。
