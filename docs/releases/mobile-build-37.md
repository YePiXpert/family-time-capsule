# 原生构建 37：竞品体验方案实现

状态：源码实现，尚未测试或构建安装包。2026-09-12 维护者要求「先不要测试了，先做」，本轮提交跳过 CI，不把旧构建的验证结果或附件当作本轮交付。产品版本仍为 `0.0.1`。

## 本轮范围

- 参考苹果照片：媒体阅读器固定返回与更多入口，画面适应屏幕空间，缩略图切换，常规时间格式和一套播放操作。文件信息、导出与兼容工具收进更多；沿用单实例播放器、异步换源和错误恢复。
- 参考 FamilyAlbum：成长页直接点选年份/月，使用同一份本机虚拟列表；年月和宝宝月龄分开表达。选择保留到用户主动改变，后台同步不切回今天。日历复用年月面板。
- 参考 Day One：旧回忆标题、正文、地点、日期精度和人物修改自动暂存本机；明确保存后排队同步。退出页面后可从「我的 → 未完成记录 → 回忆修改」继续。新记录的更多工具提供可选的「第一次」「你说的话」「生日」提示，预览后主动加入正文。

## 离线修改约定

仅对已经在本机打开、且可编辑的记忆提供旧回忆补记。SQLite 新增独立的 `local_memory_edit` 表，按服务器地址、实例、账号和家庭归属保存；清除服务器缓存不删除这些本机输入，明确清除本机资料时一并清除。

输入暂存与提交意图分开。点击保存后，后台在核对目的地身份后复用现有 PATCH 接口；每次实际发送的内容和操作编号持久保存，网络结果不明时沿用同一编号重试。同步过程中继续输入不会被回执覆盖，也不会擅自随旧提交上传。

修订冲突保存本机内容和家庭最新内容，用户可核对并重新提交，或明确放弃本机修改。读者范围、里程碑标记仍需联网；本轮没有扩展媒体替换、作品离线编辑、批量改资料或公开分享。

本机修改表不代表已经上传到家庭，也不能用旧包的验证证据证明本轮可以安装。后续恢复验证时，需要覆盖离线暂存、重启恢复、网络重试、多人冲突、身份切换及新阅读器的真实原生交互，再生成同一 main 提交的 APK 与 unsigned device IPA。
