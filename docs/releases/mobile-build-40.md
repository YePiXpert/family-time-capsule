# 原生构建 40：把记录连成日常使用流程

产品版本仍为 `0.0.1`，Android versionCode 和 iOS buildNumber 均为 40。

## 使用变化

- 首页默认展示成长记录，年月、月龄和重要时刻集中到「回看与筛选」。记录页沿用纸色主题、阅读式标题和公共主按钮。
- 保存后回到时间线，清除可能隐藏新记录的筛选，并定位刚保存的内容。发生日期较早的记录仍按原日期排列，也能通过「查看刚保存的记录」打开。
- 已保存的本机记录默认进入阅读页；「补记」返回原记录的编辑状态。未完成补记不会替换阅读版本，重新启动可以继续输入，放弃补记恢复之前的保存版本。
- 本机原件、保存记录和家庭记忆使用共同的阅读层级；范围和保存状态明确显示。整理、权限、导出与家人讲述按需展开。
- 挑片中的照片扩大为完整比例预览，保留虚拟列表和已有挑选、封面、分组规则。书架显示真实封面；成长册先呈现内容，章节可连续阅读。相册的「给家人看」可直接进入已有观看模式。

## 数据与恢复

保留草稿内的上一份已保存内容，同时维护原件引用保护；补记中移除素材不会让旧照片变成独立时间线条目，也不会删除阅读版本的原件。同步后沿用列表记录标识；已撤下的服务器记忆不会由旧草稿重新出现。

保存失败时留在输入页。账号或家庭切换后，不显示前一个家庭的阅读内容；已发布记录沿用家庭详情的权限校验和离线缓存边界。

## 验收

移动测试覆盖 SQLite 重启、保存失败、补记恢复、原件保护、同步去重、阅读权限、时间线定位和跨章节阅读。生产 HTTP 回归验证上传、读者范围、补记冲突和 Live Photo 引用。

`mobile-build.yml` 从明确的 main SHA 生成 APK 和设备版未签名 IPA。原生测试使用同一提交的 Release 应用，检查保存 → 时间线 → 阅读 → 补记 → 重启、视频播放和阅读器退出、导入挑片、观看模式、键盘与长列表；启动截图覆盖浅色、深色、大字、空库和恢复场景。最终结果以该提交的 workflow 与 artifacts 为准。

基线原生验证发现阅读器返回按钮落入系统状态栏，补上 Modal 独立安全区域；模拟器首次启动超时保留诊断，并只对该任务创建的模拟器重启一次。Expo 补丁同步更新，保留相机可用性防崩溃补丁的精确源码检查。

iOS 包由所有者自行签名。模拟器验收与 Android 包检查不能替代所有者设备的安装体验。
