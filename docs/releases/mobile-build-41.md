# 原生构建 41：随时记录，接着写，回头翻

产品版本仍为 `0.0.1`，Android versionCode 和 iOS buildNumber 均为 41。

## 使用变化

- 主导航统一为「日常 / 回看 / 我的」。日常页缩小标题区，把搜索与筛选集中在页头；普通本机保存状态汇总显示，照片与真实文字更早出现。未完成补记和待家人确认仍在对应记录上说明。
- 未写完的记录和补记可从首页直接继续；只列出当前账号、家庭、实例下有内容的草稿。已经保存、排队同步或丢弃的记录不会算作未完成。
- 当已有记录中确实存在往年同一天的内容时，首页显示回看入口；以家庭时区判断，仅使用精确日期，不把月份、年份或未知时间当作纪念日。
- 记录页优先呈现正文与照片，拍摄、录音和文件按需展开。开始录音后，完成录音始终可用。保存栏持续显示读者范围，打开同一个弹层调整，离线和重启后保持选择。
- 日常选中的记录可直接带入成长册，先呈现已选内容及真实照片，再按需调整样式和读者。精确读取跨分页的选中记录；更改读者范围会重新核验，不静默删除选择或扩大权限。
- 回看页统一进入成长册与相册。断网时，已下载内容从原来的封面入口直接打开；联网时以当前服务器列表和权限为准，认证失败、撤权、删除及服务器错误不会误当成断网继续展示旧副本。

## 数据与兼容

沿用现有草稿保存、原件保护、同步、阅读缓存及观看模式。没有新增数据库迁移。书籍材料接口兼容增加精确 ID 查询与日期精度；跨分页带入选择需要服务端也更新至本提交。

切换账号、家庭或实例时，旧草稿入口、选中记录和阅读结果立即失效，晚到的网络响应不会恢复旧内容。无法核验的选中记录保留解释与重试入口，生成仍由服务端做最终权限校验。

## 验收

移动测试覆盖草稿恢复、日期精度与时区、选择跨页保留、范围变化与晚响应、录音工具折叠、隐私持久化、离线入口和联网撤权。服务端集成测试检查精确材料选择与阅读范围。

原生 Release 验收新增「输入 → 重启 → 首页继续 → 保存 → 阅读 → 补记 → 重启」流程；既有启动、视频、相册观看、导入、键盘和长列表检查继续执行。浅色、深色、大字及恢复截图随 workflow 保留。

APK 与未签名设备 IPA 由 `mobile-build.yml` 从同一个明确的 main SHA 构建，交付以该次 workflow 的验证结果与 artifacts 为准。iOS 包由所有者自行签名；原生自动化使用模拟器。
