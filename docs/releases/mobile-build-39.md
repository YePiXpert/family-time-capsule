# 原生构建 39：新增模块回归与原生验证

2026-09-12 按维护者要求恢复测试。产品版本保持 `0.0.1`，Android versionCode / iOS buildNumber 递增到 39，承接构建 37/38 的五项竞品体验实现。安装包与 iOS 证据必须来自同一明确 main SHA 的 `mobile-build.yml`，以该次 workflow 结果为准。

## 测试发现并修复

- 已确认的「仅存资料库」请求重试时，恢复上传同意流程，不误报重复操作为修订冲突。
- 在导入批次内调整挑选，保留来自其他批次的现有草稿封面。
- 相册缓存或权限被撤下后，迟到的异步读取结果不能重新显示旧内容。
- 视频首帧之后再次缓冲有明确提示；原生进度跳转失败显示可恢复错误。
- 编辑器按打开时的内容与修订号保存基准；后台刷新发生在首个输入前，也不会让旧内容静默覆盖家人的新修改。
- 修复移动端 React 编译检查发现的状态与同步回调问题，并更新新增控件所需的原生测试替身。

## 自动化回归范围

离线编辑使用真实 SQLite 测试适配层，验证重启、网络结果不明时沿用操作编号、同步中继续输入、多人冲突、家庭隔离、磁盘失败、日期精度和冷启动缓存读取。

挑片覆盖分组与手动选择、本机持久修订冲突、批次部分加入、Live Photo 配对、只存本机与显式上传的区分，以及大批次列表、封面和相册操作。远端元数据读取不完整时，不覆盖原来已保存的完整挑选。

观看模式覆盖当前相册的可见范围、账号切换、下载撤回、长按确认退出、无导出/创建动作和播放控制；旧媒体、作品阅读和原生启动回归继续保留。服务端同时覆盖移动 API、记忆修改权限、导入去向和离线阅读包。

## 原生验证

构建 36 的 XCUITest 运行器曾因新 Xcode 不再接受 `NSStringFromCGRect` 而在编译时退出，当时没有执行播放断言。本轮修正工具链适配，并把测试运行器编译前移，让这一类错误先暴露。

原生脚本使用 Release 模拟器应用验证真实首帧、播放时间推进、暂停、拖动进度、固定布局、本机挑片与临时观看。保留 `.xcresult`、截图和去敏请求记录，并支持与 `a62dbc535d8c9c60917b73bc503d5c68fddf53be` 在同一模拟器运行环境比较滚动表现。

成功构建后，Android APK 可安装；iOS 为设备版未签名 IPA，由所有者自行签名。模拟器及包检查不等于已在所有者的实体 iPhone 上验收；纯离线且设备不支持的原件编码仍需退出观看模式后处理。
