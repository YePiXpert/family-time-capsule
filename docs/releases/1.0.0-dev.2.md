# 小美成长记 · 成长手帐更新（构建 24）

成长首页、成长册书架、记录页与「我的」采用统一的暖色手帐设计。照片、真实月龄和家人留下的话形成更清晰的层级，筛选与管理入口集中收纳；两张插画压缩为内置 WebP，离线可用。

- 导航和悬浮记录入口支持液体玻璃：iOS 26+ 使用可用的原生效果，其他支持的平台采用背景模糊。减少透明度时使用实底。
- 原生支持跟随系统、浅色、深色，以及大字显示；Web 采用同一套浅色/深色设计色值。
- 修复记录页保存栏与底部导航重叠、点击保存误入「我的」的问题。保存栏按导航实测高度避让，同时补齐顶部安全区和记录页深色样式。
- 纯本机保存成功后显示「已保存在本机」，不再把等待后续同步误报为「重试保存」。服务器发布成功与本机保存分别提示。
- 修复本机启动状态读取完成前提前显示欢迎页的问题；离线记录、同步授权、家庭权限和隐私范围保持原有规则。
- 成长册继续支持编辑、版本、PDF/EPUB 出版与主动离线收藏。

## 升级

网页在服务器升级后刷新即可。原生应用需要安装本版构建 24；营销版本仍为 `1.0.0`，产品与服务端版本为 `1.0.0-dev.2`。构建 15–23 与本版服务端兼容，构建 14 及更早版本需更新。

Android APK 已用测试密钥签名，覆盖安装需要与原包签名一致。保留尚未同步的本机内容，升级时不要先卸载旧 App。iOS IPA 是 arm64 真机未签名包，需要自行签名主应用与分享扩展，并配置对应 App Group。

服务端部署前保留完整卷备份；本版没有新增数据库迁移。附件包括 APK、未签名 IPA、运维工具、校验和与发布清单，清单记录源码提交和服务器镜像 digest。

本版为 development 通道预发布。组件测试、浏览器回归、iOS 模拟器冒烟及安装包构建分别验证；模拟器和编译结果不代表已完成真实 Android/iOS 设备的签名安装与媒体权限验收。
