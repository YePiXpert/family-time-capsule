# 原生构建 38：导入挑片与给家人看

状态：源码实现，测试与安装包构建仍按维护者要求暂缓。Android versionCode / iOS buildNumber 均为 38，产品版本 `0.0.1`。本轮没有生成 APK / IPA，也没有把以前的运行结果视作本轮验收。

## 这次导入，挑几张

入口位于本机收件和服务器导入详情。每组显示代表图和数量，展开后查看、勾选素材；支持全选、仅选代表图、手动合并已选照片、拆开照片组和选封面。可靠拍摄时间内的照片可按 30 秒窗口建议分组，其余显示为同批导入，不推断照片相似度。

分组、勾选、封面使用本机 SQLite 持久保存，按服务器实例、账号、家庭与批次隔离。取消勾选或拆组只改变挑选，不删除任何原件。「仅选代表图」只筛选照片，已选声音、视频、文档和文字保持原选择。

本机挑选可加入新草稿或已有草稿，也可调整这个批次已关联且仍可编辑的草稿。调整只影响本批媒体引用，已有正文保留；Live Photo 配对需要同时保留。仅存本机不会新增上传意图，上传到家庭资料库仍需明确选择。

服务器批次复用现有导入与资料库接口，完成的原件可按同样方式挑选后加入草稿、记忆或相册。选定封面可应用到草稿或相册，若资料已加入而封面更新失败，会说明部分完成状态。每次最多加入 200 份。服务器批次读取需要网络；纯本机导入可离线挑选。

## 给家人看

从相册更多操作或已下载相册进入独立观看页。只展示选定相册里的文字、照片、视频与声音，提供前后翻阅，不显示修改、删除、上传、导出或设置入口，也不在观看模式提交兼容衍生物任务。

离线入口复用原有下载的身份归属和权限处理。在线内容继续由服务器核对可见范围，临时观看不创建新账号或公开链接。持有人明确退出后回到原界面；这是应用内减少误操作的观看模式，不是系统级锁机。

## 实现范围与后续验证

没有新增公共 API 或服务端数据库迁移。新增本机 `local_import_selection` 表，保存挑选并用修订号防止并发覆盖；清除本机资料会一并清除。

后续需恢复验证：大批次滚动、快速多次选择的持久恢复、局部加入与 Live Photo 配对、断网与身份切换、相册内容撤权、观看页的退出和真实视频播放。构建 36 未完成的原生 XCUITest 问题仍需在恢复验证时处理，见 [构建 36 状态](mobile-build-36.md)。
