# 真实设备验收清单（REAL_DEVICE_TEST）

> 部署完成后、**正式开始保存真实家庭资料之前**，用真实手机/电脑逐项手工验收。
> 这份清单来自 RH-008：自动化测试覆盖不了真实机型编码、系统分享行为与浏览器解码差异。
> 建议打印或在测试设备上打开本页，逐项打勾并记录问题。

> 发布状态（2026-09-04）：rc.4 本地单元/集成、Playwright、生产恢复 roundtrip、
> 双平台 Expo bundle 与 Docker smoke 已完成；本分支未 push，故 rc.4 GitHub CI、APK/IPA
> 云构建及以下真实设备复选框均无新证据。当前版本是 `1.0.0-rc.4`，不是稳定版。
> 完成后请填写文末日期、设备/OS/浏览器版本与未通过项，才可升 `1.0.0`。

## 场景与检查点

### 0. 原生本地优先启动

- [ ] **0.1 首次启动免登录**：全新安装 IPA/APK，断网启动直接进入本机时间轴，不出现
  服务器登录门禁；
- [ ] **0.2 本机记录**：未连接服务器时写文字、拍照、选择照片/视频，重启 App 后仍在
  本机时间轴且原件可见；
- [ ] **0.3 可选同步**：在设置中连接服务器后才开始补传；断开服务器后本机记录、原件
  和已下载时间轴均不被删除；

### A. 输入入口

- [ ] **A1 今天拍今天传**：M1 拍摄后立即上传（手机浏览器选「照片图库」）→
  收件箱 capturedAt = 拍摄时间，timeSource = 照片内嵌时间；
- [ ] **A2 三天前的照片今天传**：选一张 3 天前的 M1 → capturedAt 应为 3 天前，
  **不是**今天；时间轴确认后出现在 3 天前；
- [ ] **A3 无 EXIF 图片**（M3 截图 / M9 微信图）→ 收件箱标记「缺少时间」（needs_review），
  手工修改时间后 timeSource 显示「你确认的时间」；
- [ ] **A4 相册批量选择**：一次勾选 5 张以上 → 逐个上传不中断、不重复保存；
- [ ] **A5 大视频**：M10 上传不超时（音频 200MB / 视频 500MB 上限内）；
  超限时收到明确「超过大小限制」提示而不是白屏；
- [ ] **A6 外部录音**：M6/M7/M8 从「文件」App 选择上传 → 可播放、进入收件箱；
- [ ] **A7 现场拍摄入口**：手机浏览器点上传 → 系统允许直接调相机拍照（不强制）。
- [ ] **A8 原生时间来源**：原生相机现场拍摄可得到现场时间；从相册选择 M3/M9 时，若系统
  不提供可靠创建时间，服务器显示 `capturedAt=null` / `import_time` / `needs_review`，不得显示
  为选择时间；受限照片权限和文件浏览入口分别验证。

### B. 格式与回放

| 素材 | iOS | Android | 桌面 Chrome/Edge |
| --- | --- | --- | --- |
| M1 JPEG | 显示缩略图/大图 | 同左 | 同左 |
| M2 HEIC | 直接显示 | 多数显示（Android 12+ 或占位） | **占位 + 下载原件（预期）** |
| M3 PNG | 显示 | 显示 | 显示 |
| M4 MOV(HEVC) | 播放 | 多数不能播（占位+下载） | 多数不能播（占位+下载） |
| M5 MP4 | 播放 | 播放 | 播放 |
| M6–M8 音频 | 播放 | 播放 | 播放 |

- [ ] **B1** 每种素材的 capturedAt 正确（M4/M5 看 ffprobe 的 creation_time，
  Docker 镜像内有 ffmpeg；缺失则回退文件时间并如实标注来源）；
- [ ] **B2 竖屏视频 M11**：播放方向正确（不横躺）；时长显示正确；
- [ ] **B3 下载原件**：事件页/占位卡的「下载原件」在三种设备都能保存原始文件
  （HEIC 下载后仍是 HEIC，**不是**被转换的 JPEG）；
- [ ] **B4 重复上传**：同一文件传两次 → 第二次明确提示「已存在相同原件」，可跳转查看。

### C. Live Photo 组合（M12）

- [ ] HEIC 与 MOV **都**出现在收件箱（两个条目，谁也没被自动删除）；
- [ ] 多选两项合并为一个事件 → 事件含 2 份素材、封面为静帧；
- [ ] 合并后两个原始文件都可下载、SHA 不变（UI 上即「都能打开且内容正确」）。

### D. 时间轴与整理

- [ ] **D1** A2 的旧照片出现在正确日期分组；年/月/天年龄与实际一致
  （出生当天 / 第 N 天 / 满月 / X 岁 Y 个月）；
- [ ] **D2 事件编辑**：把一个 8/10 事件改成 8/11 → 时间轴移动、年龄从「出生当天」变「第 1 天」；
  照片自身的拍摄时间**没有**被改动（事件页档案信息里时间来源不变）；
- [ ] **D3 合并**：5 张照片合并后收件箱清空、事件只显示一次。
- [ ] **D4 家庭墙钟跨端**：设备时区与家庭时区相同及不同各编辑一次 Inbox/Memory，Web 与
  原生往返后墙钟不变；覆盖上海午夜前后，并把家庭切到纽约核对 DST 跳变边界。
- [ ] **D5 家庭日界年龄**：在家庭本地午夜两侧核对出生当天 / 第 N 天 / 满月 / 百天，Web 与
  原生标签一致，不因设备时区或 UTC 日界少一天。

### E. 多人视角与胶囊

- [ ] 添加「外婆」等无账号成员；
- [ ] 同一事件分别以「爸爸」「外婆」留下讲述 → 两块独立显示，修改其一不影响另一；
- [ ] 创建 date 胶囊（未来日期）→ 封存后正文隐藏、开启按钮禁用；
  创建 age 胶囊（孩子 18 岁）→ 同上；
- [ ] 到期胶囊可开启、内容重现。

### F. 导出与恢复（桌面执行）

- [ ] 设置页导出 ZIP → 解压：`timeline.md` 可读且图片可见、音视频双击可播；
  manifest.json 存在；
- [ ] `node scripts/verify-export.mjs <zip>` → 全部 ✓、哈希全绿；
- [x] 按 DEPLOYMENT_CHECKLIST §7 在两个隔离 Docker 项目/卷之间完成完整 restore
  （2026-09-03：身份重绑、时间轴、事件、原件 SHA、二次导出与 verify 全绿）。

### G. 移动端体验

- [ ] iPhone「添加到主屏幕」→ 打开为全屏 standalone（无浏览器地址栏）；
- [ ] Android Chrome「安装应用」→ 同上；
- [ ] 异形屏（刘海/手势条）下导航不被遮挡（safe-area）；
- [ ] 断网打开 PWA → 显示离线提示页（不是浏览器错误）；联网后恢复；
- [ ] 手机上完成一次完整路径：拍照→上传→收件箱→确认→时间轴（≤ 2 分钟）。

### H. 原生客户端、本地数据与同步

- [ ] GitHub Actions `Native mobile packages` 同次运行产出 APK 与 unsigned IPA；
  APK 可安装，IPA 经自有 Apple 身份签名后可安装；
- [ ] 原生端没有浏览器地址栏/WebView；系统应用信息显示 bundle/package id
  `app.familytimecapsule.mobile`；
- [ ] 底部一级导航严格为“首页、时间轴、记录、收件箱、更多”，异形屏下无遮挡；记录按钮
  突出，收件箱有待整理角标，搜索从“更多”进入；
- [ ] 原生首页显示当前家庭/孩子、年龄、快速记录、待整理预览、最近记忆与回顾入口；每个
  模块都能进入对应动作，空家庭时引导留下第一条记忆；
- [ ] 登录后完整时间轴和图片封面可见；开启飞行模式并杀掉 App 后重新打开，既有时间轴
  仍可浏览；
- [ ] 飞行模式下写文字并选择一张照片：待同步数增加；彻底退出再打开，队列和照片仍在；
- [ ] 原生“记录”分别完成拍照片、拍视频、直接录音和相册多选 5 份；每份素材显示自己的
  同步状态，强制退出后原件仍在 App 私有目录；
- [ ] 首页“文字/拍照/录音/导入”分别聚焦文字框、直接拉起相机、定位录音区和直接拉起相册；
  故事、胶囊、问题及 story 搜索结果打开准确内容，不进入笼统 More；
- [ ] 恢复网络：文字/照片只进入服务器收件箱一次，重复点同步不产生重复文字或原件；
- [ ] 不进入 Web，完成“记录 → 收件箱修改标题/时间/人物/地点 → 多选合并 → 单条确认 →
  记忆详情 → 时间轴”，音频/视频均可播放；
- [ ] 原生修改草稿后在 Web 不改直接确认，标题/时间/地点/人物均保持；反向由 Web 修改后
  原生打开也一致；
- [ ] 本机 capture 确认或多项合并后，时间轴只剩一条正式事件；杀掉 App 重启仍不重复，
  断网打开正式事件仍能读取未删除的本机原件；
- [ ] 时间轴卡片可进入记忆详情；离线封面、图片画廊、音视频播放、标题/日期/年龄/人物/
  地点/家人讲述和同步状态均清晰；原生搜索结果也能进入同一详情页；
- [ ] 在记忆页新增一段文字讲述、选择作者和可见性，再修改自己的讲述；viewer 看不到新增、
  修改、合并或确认按钮；
- [ ] 收件箱加载两页以上，断网时显示可重试错误；恢复网络后不会重复已加载或已确认项目；
- [ ] 同步中途断网：上一次离线时间轴不被清空；恢复网络后可继续完成完整快照；
- [ ] 用 viewer 登录时“记录”不可写；停用账号或撤销 session 后，下一次网络同步返回登录
  过期/不可用且不泄露其他家庭数据；确认 viewer 的只读记录页不会增加 outbox；
- [ ] 服务器删除/恢复一个事件后完成同步，本机列表相应消失/重现；
- [ ] 退出前有未补传数据时出现明确警告；确认退出只清除本机数据，服务器档案不受影响。
