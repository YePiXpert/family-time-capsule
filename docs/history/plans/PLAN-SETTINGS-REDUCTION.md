## 一、现状问题

- 「我的」五行：落款、备份与恢复、本机存储、家庭与设备、外观设置。同步散在三处：备份页底部「家人一起写」卡管同步与冲突，家庭页管身份，「外观设置」里藏着自动同步开关。
- 状态说法互相打架：「我的」写「已加入家庭」，备份页却让人「开始一起写」；只有加入了家庭、第一次同步还没做时才会这样，但用户看不出是同一件事。
- 验证远端、钥匙指纹、删掉全家的远端对普通家人没有用，却和「现在同步」挨着。
- 备份页一进来就是四张卡：完整备份、本机保留的备份、开放归档、家人一起写。
- 视觉上：页底三团暖色光斑、每行一个彩色图标砖、卡片厚投影，iOS 上卡片是液态玻璃、有高光。读的地方也像在操作。

## 二、新结构

「设置」（原「我的」）：顶部一行轻页头（名字圆章、昵称、月龄，点开是宝宝资料），不再是一张大卡。下面一张实色列表：

| 行 | 副题 | 点开 |
| --- | --- | --- |
| 记录落款 | 右侧「—— 妈妈」 | 原地展开称呼 chips；有旧记录没落款时，下面一行次要文字按钮「以前 N 段还没落款」，确认后补写 |
| 家庭与同步 | 还没加入家庭／已加入，还没完成第一次同步／正在同步…／有 N 段两台手机都改过／上次同步没成功／上次同步 某时 | 家庭与同步页 |
| 数据与备份 | 上次完整备份 N 天前 · 本机 X MB | 数据与备份页 |
| 外观与隐私 | 跟随系统 · 更大文字 · 应用锁 | 外观与隐私页 |

页尾保留装饰线与「入淮清洛渐漫漫」。单独的「我的落款」页取消。

**家庭与同步**（原「家庭与设备」）：身份卡（称呼 · 角色、添加手机、设备）→ 同步卡 → 家人名单 → 管理者维护（仅管理者）→ 退出家庭。

- 同步卡只在已加入时出现，状态三种：
  - 已加入，还没完成第一次同步：说明会合并或下载，给「开始第一次同步」。
  - 已同步：上次同步、冲突「去看看」、「现在同步」、「回到应用时自动同步」开关。
  - 钥匙对不上：只报错，告诉人退出后重新加入。
- 获准页的「以后再说」回到同一个「还没完成第一次同步」状态，说法一致。
- 同步卡读本机状态。服务暂时连不上时，身份卡报错，同步卡照常显示，冲突照样能进。
- 管理者维护是家庭页里的一步：验证远端、重新生成恢复码、删掉全家的远端、家庭钥匙指纹。服务端 `DELETE /api/v1/admin/backup` 本来就只认管理者，手机端只给管理者看入口。

**数据与备份**（原「备份与恢复」）：

- 首屏一张卡：状态行（上次完整备份／进度／结果）、「保存完整备份」主按钮、停止、.xmb 脚注。
- 下面三行列表：
  - 恢复备份：进恢复页。恢复页有「从文件恢复」和「本机恢复记录」，每份记录都能恢复、另存到应用之外、删除。
  - 导出可阅读副本：进归档页（原开放归档）。
  - 本机存储：进原存储页。
- 后果照旧先说：恢复弹窗写明会换成哪份备份里的多少内容、现在的先备份一份；可阅读副本页写明信是明文、未拆封的信默认不含。

**外观与隐私**：主题、更大文字、应用锁。自动同步开关移到同步卡。

## 三、视觉（全应用）

- 页底只留纯纸色，去掉三团径向光斑。
- `Card` 在所有平台都是实色纸卡：内容色底、暖色细描边，没有投影、没有玻璃高光。读的地方都是纸：书架卡、月册行、寄语卡、信、编辑页、设置列表。
- 液态玻璃只留给操作：页面上的胶囊按钮、顶栏图标钮、底栏、记一刻圆钮、照片角标。卡里的按钮仍退回实色。
- 图标砖取消：行首只放线性图标，统一辅助色，不按功能分色。
- 月册记录行、`section` 去掉卡片投影；记一刻圆钮在 Android 上保留轻投影（它浮在内容上面）。
- 暖米纸、赤陶强调、名字圆章、落印不变。
