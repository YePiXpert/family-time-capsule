# 真机验收

自动化与模拟器结果见 [HANDOFF](../HANDOFF.md)。下列项目都还没在真机上验过，CI 通过不等于这些项通过。第一部分需要两台手机，第二部分一台就能看。

使用测试记录与独立备份；恢复演练用备用设备或可重建的测试资料。

## 一、两台手机

| 场景 | 通过标准 | 结果 |
| --- | --- | --- |
| 家庭初始化与加入 | 先抄写核对恢复码再创建；另一台扫码获准，各自身份正确 | 待验 |
| 双向记录 | 两台各写一条，带照片、录音和落款；同步后双方可读可播 | 待验 |
| 同时修改 | 两台离线改同一条，联网合并；另一版可找回，附件保留 | 待验 |
| 断网与重启 | 写作、保存、重开不丢内容；联网后同步状态明确 | 待验 |
| 停用与退出 | 停用的手机不能继续请求；最后一台管理者退出被拒，钥匙仍可用 | 待验 |
| 换机与恢复 | 从测试备份恢复，核对文字、照片、录音、信与落款；恢复码找回后能解开远端 | 待验 |
| 长期可读 | 开放归档脱离 App 能读、附件可打开，年度 PDF 可读 | 待验 |

## 二、单机手感与近期改动

来自 1.1.3 动效打磨、1.1.4 设置减法与 1.1.5 收尾。模拟器回归与截图都已通过，这里只看真机上的手感和读起来对不对。

| 类别 | 情形 | 通过标准 | 结果 |
| --- | --- | --- | --- |
| 连续操作 | 书架 → 年度册 → 月册 → 记录 → 返回；侧滑到一半松手；连点入口 | 无空屏、无重复栈、页内顶栏不闪 | 待验 |
| 返回手势 | 看原图放大后左右拖；书架横条、最近卡左右翻；编辑页正文拖选 | 不触发返回；左边缘侧滑仍能返回 | 待验 |
| 草稿 | 空草稿侧滑、已输入侧滑、录音中侧滑、保存中侧滑、保存失败 | 沿用原有提示与去处，不丢字、不重复写 | 待验 |
| 玻璃与按压 | 记一刻按下、忙碌；页面 push／pop 中途；纸卡按压 | 玻璃不消失、不只剩图标；按压看得出 | 待验 |
| 减少动态／透明度 | 进应用后去系统设置里切换再回来 | 立刻变为无转场、无按压缩放、无封信动画；关透明度后退回纸面 | 待验 |
| 底部面板 | AI 请求中收起再打开；快速连点开收；拉小横条下拉；读屏关闭 | 任务保留、不多发请求；拉过四分之一收起，否则弹回；焦点回到「AI」钮 | 待验 |
| 隐私遮挡 | AI 面板、选照片、装订预览打开时进多任务；开应用锁时切后台 | 多任务卡片只见纸面；锁盖住一切 | 待验 |
| 封信 | 成功、失败（如拆封日已过）、动画中返回、再次进入 | 只在成功后播一次；再次进入不播 | 待验 |
| 设置与纸卡 | 320 宽与大字；深色；iOS 胶囊与顶栏钮 | 设置首屏放得下，落款展开后才滚动；深色下纸卡描边清楚；按钮仍是玻璃，卡片没有高光 | 待验 |
| 家庭页离线 | 已加入家庭，断网打开家庭与同步 | 身份卡报错，同步卡和冲突入口照常 | 待验 |
| 备份确认 | 保存完整备份后分享面板取消，再来一次点「已存好」 | 取消的那次不记为已备份；「已存好」之后书架备份提醒消失 | 待验 |
| 冲突页 | 同步进行中打开冲突页 | 「用这一版」「知道了」禁用；同步留下新的一版时页面跟着出现 | 待验 |
| 应用锁 | 开应用锁后在系统里关掉锁屏密码 | 保持上锁，说明先重新打开锁屏密码 | 待验 |
