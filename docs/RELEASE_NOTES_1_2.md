家庭记忆馆与成长年册 · 1.2.0-alpha.3 prerelease

修复 iOS 首页“文字 / 拍照 / 录音 / 导入”点击后闪退。首页快捷入口会传递意图和请求参数，
底部导航在生成这些参数的链接时，因为 query-string 的不兼容导入调用了不存在的函数，
触发未处理的 TypeError 并终止应用。不带参数的底部“记录”标签不经过这条失败路径。

- 保留修复解码拒绝服务漏洞的 query-string 9.5.1；安装时修正 React Navigation 源码与
  发布 JS 的导入方式。补丁验证版本与源代码形态，避免依赖升级后静默失效。
- 新增五项调用真实导航库的回归测试，覆盖四个入口的参数生成、参数清除和中文参数解析。
- 修复相机不可用时拍照入口的另一处 iOS 原生崩溃：设置 UIImagePickerController 前检查
  相机来源与设备可用性，失败时提示从相册导入，页面仍可继续使用。
- 新增 iOS Release 模拟器实际入口测试及截图、崩溃日志采集。
- 原生展示版本 **1.2.0**，Android versionCode / iOS buildNumber 均为 **9**。

本版包含 alpha.2 的录音初始化、媒体 Range、私人详情缓存隔离与本机数据清空修复。
升级或重新登录后，需要联网打开详情一次以重新建立会话缓存；本机原件与待同步记录保留。
媒体 Range 修复还需将自托管服务器更新到本标签，仅安装移动端包不会更新服务器。

APK 为测试签名独立包；IPA 未签名，需自行签名部署。模拟器运行与包级检查不能代替
真实设备的旧包无损升级、系统分享及媒体硬件验收。不要卸载含唯一资料的旧包，请先保留
原件和完整备份。本版仍为 alpha prerelease。
