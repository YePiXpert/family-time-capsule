家庭记忆馆与成长年册 · 1.2.0-alpha.4 prerelease

本次集中优化 Web 与移动端的界面与操作体验：导航一致性、删除确认、图片懒加载、
上传防重复与超时兜底、编辑器数据防丢与实时预览，共修复与增强四十余处。

- 首页与导航：小字对比度过 WCAG AA；底部导航与桌面侧边栏入口补齐、激活规则对齐；
  只读成员的空态引导不再指向无权限页面。
- 时间线与记忆：「移到回收站」需确认；日历封面不再回退全尺寸原图；列表与阅读器
  缩略图懒加载并固定宽高比；筛选保留相册上下文；月份/年份冲突时正确回显。
- 记录与上传：访客贡献防重复提交；录音与文件选择不再互相覆盖；已选文件可见、
  可移除；上传超时后可重试；错误码替换为可读中文；批量导入支持拖拽与离开拦截。
- 书籍编辑器：离开页面自动补存未保存修改；删除内容块需确认；空章节警告集中展示
  并分级；内容块支持拖拽排序与跨章节移动；宽屏下编辑与预览并排实时同步。
- 移动端：书籍封面选择改为紧凑的展开式选择器。
- 原生展示版本 **1.2.0**，Android versionCode / iOS buildNumber 均为 **10**。

本版包含 alpha.3 的首页入口闪退与相机崩溃修复，以及 alpha.2 的录音初始化、媒体
Range、私人详情缓存隔离与本机数据清空修复。升级或重新登录后，需要联网打开详情
一次以重新建立会话缓存；本机原件与待同步记录保留。媒体相关修复需将自托管服务器
更新到本标签，仅安装移动端包不会更新服务器。

APK 为测试签名独立包；IPA 未签名，需自行签名部署。模拟器运行与包级检查不能代替
真实设备的旧包无损升级、系统分享及媒体硬件验收。不要卸载含唯一资料的旧包，请先
保留原件和完整备份。本版仍为 alpha prerelease。
