# 桉桉成长记

一家人写给她的传家册，不是相册：她记不住的这几年，爸爸妈妈和家人用文字与声音替她记下，照片只是插图；每一段时光有日期和几句话，每年装订成一本纸书，写给未来的信到 18 岁才拆；开放归档保证没有这个 App 也读得到。定位、原则、不做的事与路线次序见 [PRODUCT.md](PRODUCT.md)。

Android／iOS 应用，资料保存在本机，日常记录可离线使用。AI 由家人账号登录后可选使用，只看这一次任务交给它的东西（当前草稿、落款，或为小问题与寄语挑选的标题清单和她说的话），不看照片或整库；它的角色正从代笔转向访谈者与整理者（PRODUCT.md 第五节）。

## 使用

1. 打开应用，点「开始记录」。宝宝昵称和生日可稍后在「我的」（书架右上角的名字圆章）补充。
2. 「记一刻」（右下角的笔）里写几句话或加照片；草稿会自动保留，什么都没写就退出会自动清掉，点「保存这一刻」才成为正式记录。
3. 在「相册」选择记录、命名并保存。删除相册不会删除原记录。
4. 也可以在微信等应用里把照片、视频或文字分享给「桉桉成长记」：会存成一份草稿，照片尽量带入拍摄时间与地点，跨多天的照片也保存在这一份草稿里。
5. 定期在「我的 → 备份与恢复」导出完整 `.xmb` 备份，保存到应用之外。卸载应用会删除本机内容；应用内另保留最近 3 份本机备份供恢复（照片只存一份），有记录且超过 30 天未导出时书架会温和提醒。超过 2 GB 的备份会分成几卷，恢复时把几卷一起选中。登录家人账号后还可以开启加密远端备份：12 个词的恢复码就是钥匙，请抄在纸上；服务器只见密文。
6. 填了宝宝生日后，书架标题下有年龄行；出生、百天与周岁当天会出现纪念卡。阅读页可把一条记录一键生成「纪念卡」图片，保存、分享或打印；相册与年度册都可写扉页寄语。书架顶部可跨全部记录搜索（标题/正文/地点，支持年份、第一次、有声像、纯文字筛选）。
7. 想要隐私时，在「外观设置 → 隐私」开启应用锁，之后打开应用或回到前台需要指纹、面容或锁屏密码。
8. 年度册里可打开「这一年回顾」，回看月度封面与每一个「第一次」。新草稿正文为空时，编辑器会给一条按月龄挑选的「今天的小问题」，非故事题日登录家人账号后由 AI 结合最近记录出题，可换一条或当次不问。
9. 编辑记录时可多选「人物」chips（可就地新建），阅读页、搜索、选材与年度册都能按人物筛选；「我的 → 本机存储」里点「查看本机健康」，可看启动与写库耗时、写盘失败摘要（只留本机，不上报）。
10. 年度册里可「装订纪念册」：把这一年装订成可送印的纪念册 PDF——年份封面、统计、寄语、按月记录、「第一次」清单与落款（20×20cm 方形开本、3mm 出血、300 DPI，真分页带页码，封面可手选，寄语与「第一次」不再截断），本机生成不走网络。每年一二月，书架会提醒把去年的纪念册装订出来（装订过就不再提）。
11. 人物标记攒多了，在编辑器人物 chips 下点「整理人物」可以改名、合并或删除；合并与删除只取消标记，不动记录本身。
12. 每段时光都可以落款「谁写的」：编辑页正文框下点「谁写的？」选爸爸／妈妈／外婆…（或自填），第一次选定就成为这台手机的默认落款（「我的 → 我的落款」可改）；阅读页、纪念卡、纪念册、开放归档与搜索都带落款。
13. 家人一起写：几台手机登录各自的家人账号后，在「我的 → 备份与恢复」末尾的「家人一起写」卡里，第一台点「开始一起写」并抄下 12 个词的恢复码，其他手机点「加入」输入这 12 个词；之后回到应用或保存后 30 秒自动同步（「外观设置」可关）。同一段两台都改时留下时间新的一版，另一版留底，书架会提醒、可换回。换手机就是「加入」。
14. 阅读页可把一条记录点亮为「她说的话」：这句原话会收进书架的「她说的话」册（搜索也能按它筛选），归档与离线网页里同样有这一栏。书架点「写一封信」可以给多年后的她写信：写好封存，默认到 18 岁生日才能拆（也可提前拆封）；信可以附一段录音。「我的 → 备份与恢复」里的「开放归档」把资料导出成普通文件夹压缩包（.zip）：每条记录一个文件夹，正文是 Markdown、照片视频录音原样保存，另附离线网页 index.html，没有这个 App 也能看；可按年分卷，未拆封的信默认不带。
15. 「说一段」：录完自动转成正文初稿，接在已写内容后。iPhone 优先在本机完成；安卓或没有中文离线识别时，登录家人账号后可经主人的服务转文字，每段先问一次、可选「以后都同意」，服务器不保存声音，服务转写最长 3 分钟。录音照样保留，信里的录音只作附件。
16. 原「出生的故事」24 问并入「今天的小问题」：出生那天、怀孕的日子、名字的来历、我们怎么认识的，头六个月三天里两天优先问、那天不发 AI 请求；6–11 个月或没填生日四天里一天，满一岁不再出故事题。已写的故事作为普通记录回看，纸书归入对应月份，不再单设主题章。
17. 年度册的编者：在「装订纪念册」里让 AI 建议每月挑选、章首原话与书名，先预览、逐条去掉或不引，家人拍板后用于纸书；目录随家人同步，开放归档不带目录。

恢复会整库替换当前资料，先校验文件并询问确认；替换前自动生成当前内容的备份。系统导出面板关闭不代表文件一定已保存到外部，请确认保存位置。

若启动时资料无法读取，可在错误页选择完整备份恢复。应用会验证备份并启用独立资料库，保留原有文件，避免覆盖无法读取的内容。

## 开发

要求 Node.js 24；Android 原生构建需要 Java 21 和 Android SDK；iOS 原生构建需要 macOS、项目工作流指定的 Xcode 与 CocoaPods。

```sh
npm install
npm start
npm test
npm run typecheck
npm run lint
```

应用主体为 `mobile/`。根命令直接转发移动端任务。`server/` 提供独立的 AI 权限与上游调用服务；部署说明见 `deploy/README.md`。

## 数据与结构

- `mobile/src/local/`：界面、业务操作、SQLite、文件和备份。
- `mobile/src/sync/`：家人一起写与加密远端（密码学、状态、传输、引擎、纯函数三方合并 `merge.ts`、一次同步 `family.ts`、自动同步 `auto.ts`、「家人一起写」卡、冲突页与恢复码页）；除 AI 客户端外唯一允许联网的目录，`mobile/scripts/local_boundary.py` 盯着这条线，也不许 `src/sync`／`src/ai` import 本机页面组件。
- `mobile/modules/share-intake/`：系统分享接收的原生桥接。
- SQLite `anan-local-v1.sqlite` 与文档目录 `anan-v1/` 独立保存正式本机资料。
- 旧版本均为测试数据，本轮从空库开始，不迁移旧账号、服务端数据，也不自动删除旧目录。
- 资料库按记录、素材等实体分条保存，一次改动只重写动过的那几条；Build 62 及更早的旧库在第一次打开时自动换成这个结构，失败则原样保留旧库。备份按块读写并校验 SHA-256，素材按内容去重，清单分段存放因此没有大小上限；旧格式备份仍可恢复。所有数据修改串行提交，写入成功才更新界面；恢复在写队列之外进行并显示进度。应用内自动保留最近 3 份可读文件名的本机备份，超出自动清理；启动恢复推荐位只放完整校验通过的备份。素材在导入时校验并在闲时巡检，缩略图随素材保存、恢复时自动重建。Build 70 起应用内保留的备份是 `.xmbm` 清单 + 按内容哈希存放的 blob 库（三份只占一份照片的空间），导出的 `.xmb` 由 blob 库拼出、超过 2 GB 分卷；远端备份在手机上逐块加密后上传，对象 id 与 nonce 由恢复码派生，服务端只存密文与清单索引。Build 72 起一台服务就是一家人：每台手机把自己的全量清单发布到家庭对象空间（`sync/manifest.xmbm`，不占三份保留位），拉别人的清单做三方合并；删除靠 `tombstones` 墓碑，合并之基与已知版本在 `anan-v1/sync/base.json`、冲突留底在 `conflicts.json`、本机同步状态在 `state.json`；草稿、选材与设置不同步。

## 发布

只从 main 构建。`ci.yml` 检查本机存储与备份测试、类型、代码规范和移动端打包；`mobile-build.yml` 检查 Android／iOS 原生流程并生成 APK 与未签名设备 IPA。IPA 需要持有者自行签名安装。

原生出包通过质量检查后，并行构建 Android、iOS 真机 IPA 和 iOS 模拟器应用。模拟器应用与 XCUITest runner 只编译一次，以保留权限和符号链接的压缩包传给两个独立任务，并行验证启动／数据恢复与完整界面回归；接收时核对源提交、CPU 架构和 Xcode 版本。GitHub Release 必须等所有构建和两组 iOS 验证通过才发布，提前生成的 IPA 不代表已交付。CocoaPods 只缓存依赖下载，每次仍运行安装；启动截图 OCR 只编译一次，原有崩溃观察时间与检查不减少。这会增加同时使用的 macOS runner 数量，实际节省时间取决于排队和模拟器冷启动；完成后检查一次结果，不轮询等待。

当前版本：**1.0.2**（构建号 75；含 Build 73「说一段」、74 的 24 个问题（现已并入「今天的小问题」）、75「访谈者」、76「年度册的编者」，加 1.0.1 的界面焕新与 2026-09-22 的复核、键盘避让修复；此后仍不加新功能、只做优化。`v1.0.1` 的标签出包在 iOS 回归环节失败、没有发布，内容并入本版）。安装包来自 GitHub Release `v1.0.2`（是否已发布、校验和以 HANDOFF 第一节为准；两个包必须来自同一 main 提交）。安装前先把服务端部署到含转写端点与新 writingMode 的版本（见 `deploy/README.md` 与 HANDOFF 第一节）。设计规则见 [DESIGN.md](DESIGN.md)。 main 上已有 **1.0.3「减法」**（未出包）：拿掉出生的故事模块（问题并入小问题）、写信引导、时光系列、足迹、长图、重放、分成几件事、AI 分组与起个头，AI 不再看照片；细目见 CHANGELOG 顶节，旧数据仍可读、可恢复、可同步。

## 书架与回看

书架首页最上面是「最近」翻页条：整宽的时光卡左右翻，标题右侧「随便翻翻」随机翻开一段（阅读页里可以「再翻一页」一直翻）；往下按年份分书架：每个年份一行衬线标题、「N 段时光 · N 个第一次」与「翻开年度册」，名下是最近 6 个月的月册封面条，更早的年份收成「往年」几行；合集区仅在有「第一次」或「她说的话」时出现；再往下合集、相册与时间胶囊都是一行一本的书册列表（小封面 + 书名 + 说明）；空的「专题册」与「时间胶囊」不带区标题，各只留一行「新建相册」／「写一封信」，有内容时才显示区标题、书册行与右侧新建入口；年度册内有当年统计、「爸爸妈妈的话」年度寄语（可让 AI 依记录标题与「第一次」清单起草一版，纯文字、核对后保存）、这一年的第一次和各月小册，也可打开「这一年回顾」或装订纪念册 PDF。月册按日期分区展示小图网格，点击记录查看大图和全文。搜索按需展开，草稿集中在一条入口，点击箭头查看其他草稿。「记一刻」位于右下角的悬浮按钮。往年的同一天有多条记录时，「那年今日」横滑卡片条可以逐条翻看。

## AI 使用

空服务第一次进「我的 → AI 设置」创建主人账号（仅此一次）；家人用主人创建的账号（用户名＋密码）登录，一个账号可登多台设备，换手机直接登录。主人可管理成员、设备和每日额度。生产内容 AI 已切换至小米 MiMo V2.6 Pro，服务端现有内容模式统一使用；云端语音转写为 MiMo V2.5 ASR，无需选择模型（见 deploy/README.md）。

编辑页工具栏只有一个 AI 图标，点开是底部面板。「写记录」下，「润色我的文字」只发送当前事情的标题、正文和落款（正文一次最多 2000 字，超限明确提示、不会自动截断）；「访谈者 → 追问我」只根据当前草稿的文字问问题。结果先预览，可全部采用或只采用标题、正文，采用前不覆盖原文；内容改动后旧建议过期。收起面板保留任务与结果，仍有未查看的结果时图标显示小圆点。每张照片独立保留拍摄信息。模型由 VPS 服务调用，API Key 不进入安装包；生产使用 MiMo V2.6 Pro。

「追问我」根据当前草稿的文字问 1～3 个问题，点一条才追加到正文；「第一次」也只建议，由你决定是否标上。「今天的小问题」在非故事题日、登录且同意 AI 范围后，一天一次由 AI 结合最近标题出题，失败退回本机清单；「换一个」只换本机问题，不再花额度。两种访谈各计一次写作额度，问题先展示再采用。

AI 只看这一次任务交给它的东西：这件事的标题、正文与落款（润色）；这一年的记录标题、第一次、她说的话与已写寄语（寄语）；当前草稿、落款、月龄、日期与最近 10 条记录的标题和日期（追问）；月龄、今天日期、最近标题与最近 7 天的问题（小问题）。编者模式只在家人明确点「AI 建议目录」并确认本次说明后，发送这一年的标题、正文、落款和日期（以及记录 id、第一次／她说的话／有无照片标记），不含照片和别的年份，服务端不保存；超过 400 段只送最新 400 段，长正文按总量截短。AI 不发送照片；其他模式不发送别的记录的正文；结果都先预览再采用。同意书已升版，原先同意过的设备使用时会重新确认范围。

网络中断可重试原请求；过期结果需要明确重新生成；上游失败或超时的请求不消耗当日额度。年度寄语起草只发送记录标题、「第一次」清单、她说的话，以及你已经写下的寄语（让 AI 避开你说过的话），不发送记录正文与照片；计一次写作额度。每日额度以 UTC 00:00 重置。照片和记录的本机备份不包含 AI 设备凭证。远端备份的钥匙不在服务端，也不随本机备份走：只在这台手机的系统钥匙串与抄下的恢复码里。

「说一段」的服务转写只发送这一段 m4a 录音，经主人的服务交给小米 MiMo；不发送正文、照片或整库，服务器不保存声音。每段先征得转写同意，可选「以后都同意」（只记在这台手机上，与其他 AI 同意分开）；一次转写计一次写作额度。iPhone 支持中文本机识别时，声音不离开手机、不用登录，也不消耗服务额度。
