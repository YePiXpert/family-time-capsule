# 桉桉成长记

在 Android／iOS 手机上记录文字、照片、视频和声音，整理相册，随时回看。照片、文字与相册保存在本机，日常记录可离线使用。可通过主人的邀请开通 AI 整理与文案功能，使用时才发送所选照片的缩略图。

## 使用

1. 打开应用，点「开始记录」。宝宝昵称和生日可稍后在「我的」补充。
2. 「记一刻」中输入内容或添加素材；退出时保留草稿，明确保存后成为正式记录。
3. 在「相册」选择记录、命名并保存。删除相册不会删除原记录。
4. 也可以在微信等应用里把照片、视频或文字分享给「桉桉成长记」：会存成一份草稿，照片尽量带入拍摄时间与地点，并建议按拍摄日期分组。
5. 定期在「我的 → 备份与恢复」导出完整 `.xmb` 备份，保存到应用之外。卸载应用会删除本机内容；应用内另保留最近 3 份本机备份供恢复，有记录且超过 30 天未导出时书架会温和提醒。
6. 填了宝宝生日后，书架标题下有年龄行；出生、百天与周岁当天会出现纪念卡。阅读页可把一条记录一键生成「纪念卡」图片，保存、分享或打印；相册与年度册都可写扉页寄语。书架顶部可跨全部记录搜索（标题/正文/地点，支持年份、第一次、有声像、纯文字筛选）。
7. 想要隐私时，在「外观设置 → 隐私」开启应用锁，之后打开应用或回到前台需要指纹、面容或锁屏密码。
8. 书架「时光系列」里，为同一个姿势或场景每月收一张照片，排成成长时间线，缺口月份有虚位卡提醒；满两张可导出横排对比卡。年度册里可「重放这一年」：全屏幻灯逐张回看每月封面与每一个「第一次」。新草稿正文为空时，编辑器会给一条按月龄挑选的「今天的小问题」，可换一条或当次不问。
9. 编辑记录时可多选「人物」chips（可就地新建），阅读页、搜索、选材与年度册都能按人物筛选；书架「足迹」按拍摄位置聚类列出她常去的地方；「我的 → 本机存储」里有「本机健康」，可看启动与写库耗时、写盘失败摘要（只留本机，不上报）。
10. 年度册里可「导出成长册」：把这一年装订起来——印章年份封面、统计、寄语、十二月网格、「第一次」清单与落款。可选一张长图（适合分享）或按 A4 分页的 PDF（适合打印成册），本机生成不走网络。「重放这一年」默认无声，也可以从已有录音里挑一段做配乐。
11. 人物标记攒多了，在编辑器人物 chips 下点「整理人物」可以改名、合并或删除；合并与删除只取消标记，不动记录本身。

恢复会整库替换当前资料，先校验文件并询问确认；替换前自动生成当前内容的备份。系统导出面板关闭不代表文件一定已保存到外部，请确认保存位置。

若启动时资料无法读取，可在错误页选择完整备份恢复。应用会验证备份并启用独立资料库，保留原有文件，避免覆盖无法读取的内容。

## 开发

要求 Node.js 24；Android 原生构建需要 Java 21 和 Android SDK；iOS 原生构建需要 macOS、项目工作流指定的 Xcode 与 CocoaPods。

```sh
npm install
npm start
npm test
npm run typecheck
npm run lint
```

应用主体为 `mobile/`。根命令直接转发移动端任务。`server/` 提供独立的 AI 邀请、权限和 CPA 转发服务；部署说明见 `deploy/README.md`。

## 数据与结构

- `mobile/src/local/`：界面、业务操作、SQLite、文件和备份。
- `mobile/modules/share-intake/`：系统分享接收的原生桥接。
- SQLite `xiaomei-local-v1.sqlite` 与文档目录 `xiaomei-v1/` 独立保存正式本机资料。
- 旧版本均为测试数据，本轮从空库开始，不迁移旧账号、服务端数据，也不自动删除旧目录。
- 资料库按记录、素材等实体分条保存，一次改动只重写动过的那几条；Build 62 及更早的旧库在第一次打开时自动换成这个结构，失败则原样保留旧库。备份按块读写并校验 SHA-256，素材按内容去重，清单分段存放因此没有大小上限；旧格式备份仍可恢复。所有数据修改串行提交，写入成功才更新界面；恢复在写队列之外进行并显示进度。应用内自动保留最近 3 份可读文件名的本机备份，超出自动清理；启动恢复推荐位只放完整校验通过的备份。素材在导入时校验并在闲时巡检，缩略图随素材保存、恢复时自动重建。

## 发布

只从 main 构建。`ci.yml` 检查本机存储与备份测试、类型、代码规范和移动端打包；`mobile-build.yml` 检查 Android／iOS 原生流程并生成 APK 与未签名设备 IPA。IPA 需要持有者自行签名安装。

当前本机版：Build 63。两个包必须来自同一 main 提交。设计规则见 [DESIGN.md](DESIGN.md)。

## 照片浏览

书架首页按年排列年度册，每一年自动汇成一册；年度册内有当年统计、「爸爸妈妈的话」年度寄语（可让 AI 依记录标题与「第一次」清单起草一版，纯文字、核对后保存）、这一年的第一次和各月小册，照片足够的年份可全屏「重放这一年」。月册按日期分区展示小图网格，点击记录查看大图和全文。搜索按需展开，草稿集中在一条入口，点击箭头查看其他草稿。「记一刻」位于右下角的悬浮按钮。往年的同一天有多条记录时，「那年今日」横滑卡片条可以逐条翻看。

## AI 使用

在「我的 → AI 设置」输入邀请码并为设备命名。主人可管理成员、设备和每日额度。AI 固定使用 DeepSeek Flash High，无需选择模型。

编辑页工具栏只有一个 AI 图标，点开是底部面板。「写记录」下，「AI 生成」按照片和拍摄信息写出短标题与正文，「润色我的文字」只发送当前事情的标题和正文（正文一次最多 2000 字，超限明确提示、不会自动截断）；「整理照片 → 按事情分组」用于新建草稿，至少两张照片，预览里可调整照片归属，画面摘要只用于辨认分组、不写入正文。结果先预览，可全部采用或只采用标题、正文，采用前不覆盖原文；内容改动后旧建议过期。收起面板保留任务与结果，仍有未查看的结果时图标显示小圆点。同一天可以有多件事，每张照片独立保留拍摄信息。DeepSeek Flash High 经 VPS 的 CPA 调用，API Key 不进入安装包。

一次最多分析 100 张照片，自动按日期分批。网络中断可重试原请求；过期结果需要明确重新生成；上游失败或超时的请求不消耗当日额度。年度寄语起草只发送标题与「第一次」清单，计一次写作额度。每日额度以 UTC 00:00 重置，写文案时分析的图片也计入额度。照片和记录的本机备份不包含 AI 设备凭证。
