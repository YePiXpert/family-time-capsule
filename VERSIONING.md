# Mobile versions

Every delivered mobile update increments both `mobile/app.json` native build numbers together. Use the next number after the highest shipped build; retries reuse the same version and build number.

The Android APK and unsigned arm64 device IPA must be generated by `mobile-build.yml` from the same main commit. Record source SHA, package SHA-256, CI and native verification results alongside the downloads. The optional AI service in `server/` is deployed separately; see `deploy/README.md`.
